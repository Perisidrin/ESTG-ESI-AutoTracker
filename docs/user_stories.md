US01 - Gestão de Veículos: Como utilizador, quero adicionar um novo veículo (indicando marca, modelo e matrícula) ao sistema, para poder gerir os gastos e manutenções dessa viatura específica.

US02 - Registo de Abastecimentos: Como utilizador, quero registar um abastecimento (ao inserir a data, os litros, o custo e a quilometragem atual), para monitorizar os meus gastos com combustível e o consumo do carro.

US03 - Registo de Manutenções: Como utilizador, quero registar uma intervenção mecânica (ex: mudança de óleo, troca de pneus) com a respetiva data e custo, para manter um histórico organizado das reparações.

US04 - Gestão de Prazos (Alertas): Como utilizador, quero registar a data limite do seguro e da próxima inspeção obrigatória, para que o sistema emita um alerta sobre esses prazos no ecrã principal e eu não me esqueça de os renovar.

US05 - Consulta de Histórico: Como utilizador, quero aceder a uma lista cronológica com todas as despesas e intervenções registadas num veículo, para conseguir saber quando foi a última revisão ou abastecimento.

US06 - Dashboard (Painel de Resumo): Como utilizador, quero visualizar um painel inicial com o resumo total de gastos do mês atual, para ter uma noção clara do impacto no meu orçamento mensal.
