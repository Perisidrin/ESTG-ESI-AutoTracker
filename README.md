# ESTG-ESI-AutoTracker

## Descrição do Projeto
O **AutoTracker** é uma aplicação web, desenvolvida para facilitar a gestão e manutenção de veículos (carros, motas, etc.). O sistema permite aos utilizadores registar e monitorizar despesas recorrentes, como por exemplo os abastecimentos feitos, as manutenções periódicas, pagamentos de seguros e datas de inspeção, de forma a manter todo o histórico do veículo centralizado numa única base de dados.
